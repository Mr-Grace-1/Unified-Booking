# Public Assets Directory

This folder contains all static assets used in the application.

## Structure

```
public/
├── icons/
│   ├── integrations/     # Third-party service icons
│   └── ui/              # UI element icons
└── images/
    └── avatars/         # User avatars (if needed)
```

## Usage

All images in this folder are served statically and can be accessed via:
- `/icons/integrations/stripe.svg`
- `/icons/ui/calendar.svg`
- etc.
